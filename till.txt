PHASE 2 - ORGANIZATIONS, MULTI-TENANCY, ROLES & USER MANAGEMENT  [DONE]

Goal
  Multi-organization support with per-org roles and tenant isolation.

Design
  Users are GLOBAL identities. Access is granted through
  OrganizationMember (per-org role + status). Each session carries an
  activeOrganization. Registration is OPEN (multi-org self-serve):
  POST /auth/register creates a global user and, when organizationName is

  Join existing orgs via invitation accept. Login sets the user's first
  membership as the active organization.
